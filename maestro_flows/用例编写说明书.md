适用环境：Windows + Maestro CLI 2.12.1 + 外置 chromedriver 158
运行入口：`H:\Study\BooxTilesAutoTest\maestro_flows\run_web.ps1`

---

## 一、一个 flow 文件的基本结构

每个 `.yaml` 文件分两部分，用 `---` 分隔：

```yaml
url: https://mika.boox.com   # 上半部分：配置（Web 用 url，App 用 appId）
---                          # 分隔符
- launchApp                  # 下半部分：操作命令列表
- assertVisible: "Import books"
- tapOn: "Import wallpapers"
```

- **Web 测试**：顶部写 `url: 网址`，`launchApp` 会打开这个网址
- **App 测试**：顶部写 `appId: 包名`，如 `appId: com.boox.mika`
- 一个 `---` 下面可以写任意多条命令，按顺序执行

> 如果将来要改测试站点，只改第一行的 `url` 即可，下面命令都不用动。

## 二、元素定位（选择元素的方法）

几乎所有操作命令（点击、断言、输入）都要先"选中元素"。Maestro 提供 4 种定位方式，**优先级从高到低**：

| 方式 | 写法 | 说明 |
|---|---|---|
| 文本简写 | `- tapOn: "Import books"` | 最常用，按页面可见文字匹配 |
| id（最可靠） | `- tapOn:\n    id: "loginButton"` | 按 accessibility id，Web 上对应元素的标识属性 |
| 正则 | `- tapOn: ".*Save.*"` / `id: ".*floating.*"` | 用 `.*` 做模糊匹配 |
| 坐标（最后手段） | `- tapOn:\n    point: "50%,50%"` | 屏幕百分比坐标；也可用绝对像素 `"100,200"` |

带多个参数的写法示例：

```yaml
- tapOn:
    text: "Submit"
    index: 0              # 多个匹配时取第 0 个（如有重复文本）
```

```yaml
- tapOn:
    text: "A text with a hyperlink"
    point: "90%,50%"      # 点这个元素内部的右侧位置
```

**建议**：能用文字就用文字，能用 id 就用 id，尽量别用坐标（页面一改就失效）。

## 三、点击与手势操作

### 单击 tapOn

```yaml
- tapOn: "Import books"
- tapOn:
    id: "plus_button"
    repeat: 5             # 连点 5 次
    delay: 200            # 每次间隔 200 毫秒
```

### 双击 / 长按

```yaml
- doubleTapOn: "图片缩略图"
- longPressOn: "文件名"
```

### 滑动 swipe

```yaml
# 按方向（LEFT / RIGHT / UP / DOWN）
- swipe:
    direction: DOWN

# 从屏幕 90% 处滑到 10% 处
- swipe:
    start: 90%, 50%
    end: 10%, 50%

# 慢速滑动（duration 越大越慢，单位毫秒，默认 400）
- swipe:
    direction: LEFT
    duration: 2000

# 从某个元素开始滑
- swipe:
    from:
      id: "feeditem_identifier"
    direction: UP
```

### 滚动 scroll

```yaml
- scroll                          # 向下滚动一屏
- scroll:
    direction: UP                 # 向上滚动

# 一直滚直到看到某元素（超时 10 秒）
- scrollUntilVisible:
    element: "Footer Text"
    direction: DOWN
    timeout: 10000
```

### 返回

```yaml
- back                            # 返回键（Web 上相当于浏览器后退）
```

## 四、键盘与文字输入

### 输入文字 inputText

```yaml
# 简写：先点输入框，再输入
- tapOn: "Search"
- inputText: "Hello World"

# 展开写法（带 label，让报告更易读）
- inputText:
    text: "tester01@o-in.me"
    label: "输入测试账号"
```

中文 / emoji 从 Maestro 2.7.0 起支持（你是 2.12.1，支持）：

```yaml
- tapOn: "搜索框"
- inputText: "你好世界"
```

### 删除文字 eraseText

```yaml
- eraseText: 5        # 删掉最后 5 个字符
- eraseText           # 不写数字则清空全部
```

### 按键 pressKey

**注意：键名是小写，且一次只能按一个键。**

```yaml
- pressKey: "enter"          # 回车（提交表单常用）
- pressKey: "backspace"      # 退格
- pressKey: "tab"            # Tab 切换焦点（Android 有效）
- pressKey: "home"           # Home 键
- pressKey: "volume up"      # 音量+
```

常用键名：`enter`、`backspace`、`tab`、`home`、`lock`、`volume up`、`volume down`。
Web 表单场景最常用的是 `enter` 和 `tab`。

### 收起键盘 hideKeyboard

```yaml
- tapOn: "Search"
- inputText: "keyword"
- pressKey: "enter"
- hideKeyboard              # 收起软键盘（移动端常用）
```

完整输入示例：

```yaml
- tapOn: "Search field"
- inputText: "Hello World"
- eraseText: 5
- inputText: "New text"
- hideKeyboard
```

## 五、断言（验证结果）

### 可见 / 不可见

```yaml
- assertVisible: "Import books"
- assertVisible:
    id: "loginButton"
- assertVisible:
    text: "Count: .*"        # 正则匹配
    enabled: true            # 同时要求元素是可点击状态
- assertNotVisible: "Error message"
```

### 等待元素出现

```yaml
- extendedWaitUntil:
    visible: "Dashboard"
    timeout: 15000           # 最多等 15 秒
```

> Maestro 对普通命令自带最多约 5 秒自动等待，通常不需要手写 sleep。需要更长等待时用上面的命令。

### 等待动画结束

```yaml
- waitForAnimationToEnd
```

### 条件断言（高级）

```yaml
- assertTrue:
    condition: "${output.text == 'Success'}"
```

## 六、流程控制与复用

### 重复执行 repeat

```yaml
- repeat:
    times: 3
    commands:
      - tapOn: "Next"
      - assertVisible: "Page.*"
```

### 条件执行 runFlow（当满足某条件时才跑某个子流程）

```yaml
- runFlow:
    when:
      visible: "Cookie Banner"
    file: dismiss_cookies.yaml
```

### 调用另一个 flow

```yaml
- runFlow: login.yaml
```

把登录流程抽成 `login.yaml`，多个用例都能复用，这就是 Maestro 版的 Page Object 思路。

### 重试

```yaml
- retry:
    maxRetries: 3
    commands:
      - tapOn: "Load more"
```

## 九、运行与调试

### 运行指定 flow

修改 `run_web.ps1` 最后一行里的文件名，或复制一份脚本改路径。


## 十、常见坑

| 现象 | 原因 / 处理 |
|---|---|
| 中文断言失败 | 文件编码问题或页面文字含间隔点，如「文石·咪卡」≠「文石咪卡」；优先用英文可见文本断言 |
| `ChromeDriver only supports Chrome version xxx` | 本机 Chrome 升级了，重新下载对应版本 chromedriver 覆盖 `chromedriver\chromedriver-win64\chromedriver.exe` |
| 提示禁止运行脚本 | 用 `powershell -ExecutionPolicy Bypass -File run_web.ps1` |
| 元素找不到 | 用 `maestro hierarchy` 或 `maestro studio` 看真实 id / text |
| 输入中文失败 | 确保先 `tapOn` 聚焦输入框，再 `inputText` |
| 页面没加载完就断言 | 用 `extendedWaitUntil` 或 `waitForAnimationToEnd` |
